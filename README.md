# Task 02 - Image Generation with Pre-trained Models

## Overview
This repository contains the implementation for Task-02 completed during the Generative AI Internship at Prodigy InfoTech. The task demonstrates generating synthetic images from text prompts using pre-trained diffusion models.

## Implementation Details
* **Model Used:** Stable Diffusion v1.5 (`runwayml/stable-diffusion-v1-5`)
* **Framework:** PyTorch, Hugging Face `diffusers`, `transformers`
* **Environment:** Google Colab (T4 GPU Accelerated)

## Sample Output
* **Prompt:** *"A futuristic cyberpunk city at sunset, highly detailed, digital art, 8k resolution"*
* **Negative Prompt:** *"blurry, low quality, distorted, extra limbs, bad anatomy"*
